# Calculator Interactiv

A simple interactive calculator built with vanilla HTML, CSS and JavaScript. Supports basic arithmetic operations via both mouse clicks and keyboard input.

## Features

- Addition, subtraction, multiplication and division
- Keyboard support — type numbers and operators directly, press Enter to calculate
- Backspace to delete the last character or operator
- Clear button (C) and keyboard shortcut (C / Delete)
- Division by zero error handling

## Tech Stack

- HTML5
- CSS3
- JavaScript (vanilla)

## How to Run

No installation needed. Open `index.html` in any browser.

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `0–9` | Enter number |
| `+ - * /` | Enter operator |
| `Enter` | Calculate result |
| `Backspace` | Delete last character |
| `C` / `Delete` | Clear display |

- Managing application state with variables
